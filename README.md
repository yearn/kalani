# Kalani
Yearn vault super center

## lfg
```sh
cp packages/web/.env.example packages/web/.env
# configure packages/web/.env
bun i
bun dev
```

## Commands

| Command | Description |
|---------|-------------|
| `bun i` | Install project dependencies |
| `bun dev` | Start frontend dev server |
| `bun test` | Run tests |
| `bun run build` | Build for production |
